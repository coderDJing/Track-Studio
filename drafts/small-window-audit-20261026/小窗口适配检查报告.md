# FRKB 小窗口适配检查报告

日期：2026-10-26（Asia/Shanghai）
基线：`7f08fcccbd379b0b334d1f60a310094d3e3ebaa5`
范围：全局布局与弹层入口代码清查 + Mac 开发版有限数据实测；**不是所有业务状态的全覆盖验收**。

## 1. 总体结论

**当前不能认定 650 高度下具备完整可用性。** 最小窗口实测存在弹窗拖动后缩窗丢失，以及欢迎页快捷键说明被截断且不能通过滚轮访问的问题。多数已打开的业务配置弹窗在初始居中状态下标题、内容和底部按钮可访问；设置与同步设置的长内容可正常滚动，不能将它们误报成“看不到下面的内容”。

不建议先提高最小高度。弹窗丢失来自拖动边界和缩窗校正缺失，提高下限不能根治；欢迎页应适应剩余空间或提供滚动。尚无证据证明必须把最小高度改为 720/780 才可使用。

用户最初指定 Windows `D:\playground\FRKB_Rapid-Audio-Organization-Tool-3`，随后明确接受在当前 Mac 检查。当前实际工作区是 `/Users/wzz/playground/FRKB_Rapid-Audio-Organization-Tool`。Vue 布局可参考同提交结果，但 Windows 原生窗口、225% 缩放、字体度量和最大化边界不能视为已经实测。

## 3. 实测问题（按严重程度）

### P1 / F01：弹窗拖动后缩窗，整个弹窗移出视口

- 入口：右上角设置，拖动弹窗标题。
- 实测条件：Mac 开发版，明色中文；窗口图像先 1260×650，再 1260×780，再缩回 1260×650。
- 复现步骤：650 窗口打开设置；把设置标题从约 (630,114) 拖到 (630,625)；放大窗口到 780 高；再将标题从约 (630,644) 拖到 (630,748)；缩回 650。
- 实际结果：只剩遮罩，标题、正文、底部关闭按钮全部不可见。滚动正文不能恢复标题位置；鼠标无法抓到标题拖回。**Esc 已验证可以关闭恢复，所以不是不可恢复死锁。**
- 中间状态也可复现：在 650 高窗口直接把标题拖到底部，正文和底部按钮会被裁掉，但标题仍可抓回。
- 原因：`dialogDrag.ts` 仅约束顶边 >=35；左右与底边不约束；transform 持续保存，没有 resize/可用区域变化时重新钳制。全局 `.dialog` 使用 `overflow:hidden`，所以被移出去的内容无法通过遮罩滚动访问。
- 影响范围：所有使用该指令的弹窗都存在同类代码风险；**仅设置弹窗完成了这条实测，不能写成所有弹窗均已复现**。
- 修复方向：统一拖动边界策略，至少保留完整标题和关闭入口；resize、内容尺寸变化时重新计算可用区并调整 transform；恢复时避免跳动，确保可滚动正文与固定页脚仍可达。

### P2 / F02：欢迎页快捷键说明被截断，没有可用滚动

- 入口：未打开歌单时的欢迎页；切换双轨/浏览器模式。
- 实测：650 目标窗口，双轨明色中文、浏览器暗色英文；编辑模式暗色英文的当前空状态未见同样截断。
- 步骤：650 高窗口显示欢迎页；观察底栏附近；将指针放在右侧欢迎内容区域并向下滚动多页。
- 实际结果：双轨页底部多行快捷键和部分装饰区域被裁掉；浏览器英文页的 Show/Hide 等底部说明被截断；滚轮操作后截图内容未向下移动。新建/导入主按钮仍可见，不应描述为所有主界面操作不可用。
- 原因：welcome 容器 `height:100%`、居中、`overflow:hidden`；内部内容 `flex-shrink:0`。双轨模式还固定占用 372px，剩余区域约 179px（以本轮截图坐标计），不足容纳全部快捷键说明。
- 修复方向：欢迎内容单独滚动，或在低剩余高度时压缩/隐藏纯装饰，允许内容起始对齐；不要缩到文字不可读，也不要仅通过扩大窗口规避。

### P3 / F03：颜色面板初次展开被设置正文滚动区裁切，但可通过滚动访问

- 入口：设置 → 主题色 → 多色圆形按钮。
- 实测：650 目标窗口，明色英文初次展开；明色中文补测少量滚动。
- 步骤：设置正文在顶部时展开颜色面板；观察底部 HEX 输入行；在面板右侧正文空白处向下少量滚动。
- 实际结果：初次展开时 HEX 输入及预览行被页脚上方的滚动边界裁掉；少量滚动后完整可见。**这是浮层定位体验问题，不是永远无法访问。**
- 原因：ColorPicker 面板是祖先内 absolute，固定向下展开，无 Teleport/边界翻转，受 OverlayScrollbars 可视区裁切。
- 修复方向：统一浮层锚点定位，依据可用空间翻转/限制高度，脱离滚动祖先裁切；跟随滚动/resize 更新位置。
