使用帮助

从这里开始。

演出前，留一点时间做好准备。

01

连接 U 盘

连接 U 盘后，在系统「文件」App 中确认它已出现，再回到 Track Studio 选择 U 盘根目录。如果无法识别，检查转接头、线缆和供电。

02

编辑与备份

编辑会写入你选择的曲库文件。建议在重要演出前备份 U 盘，并在保存完成后确认曲库可正常打开。保存期间保持连接。

03

离线副本

使用离线功能时，副本及待同步的编辑会保存在设备上。删除离线副本前，请先确认不再需要其中未同步的修改。

需要帮助？

联系我们时，请说明 iPhone 型号、iOS 版本以及遇到的问题。不要发送音乐或曲库文件，除非你愿意并确认可以分享。
